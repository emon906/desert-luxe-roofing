# Desert Luxe Roofing

Create a premium website for Arizona Roofers.

Use a luxury warm cream + warm green color palette. Bright, elegant, smooth and expensive-looking. No dark theme.

Exactly 7 mixed sections:

Unique luxury Hero Banner with bold headline + strong CTA.

About + Trust section featuring 2 Reviews and Arizona service coverage.

Services + large custom Image Placeholder.

Premium full-width Video/Reels Placeholder for my own videos.

Projects section with mixed Image Placeholders + short text.

Creative Image + Video mixed showcase with custom media placeholders.

Contact / Free Estimate CTA with the Phoenix location and service areas.

Important: I already collected custom roofing images and reels. Do NOT generate or add stock images or videos. Create premium empty media placeholders so I can add my own content later.

Service areas include Phoenix, Scottsdale, Tempe, Surprise, Tucson, Gilbert, Chandler, Flagstaff, Carefree and Queen Creek.

Make everything highly responsive, extremely smooth and premium with subtle animations, luxury spacing and an especially impressive hero banner.
